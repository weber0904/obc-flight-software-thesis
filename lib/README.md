# External Dependencies

The project pins dependencies as Git submodules:

- `fprime/`: the Apache-2.0 F Prime v4.1.0 project fork
- `libcsp/`: the MIT-licensed libcsp/csp-es project fork

Clone with `--recurse-submodules` or run `git submodule update --init
--recursive`. Exact revisions and modification boundaries are recorded in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) and
[`release/RELEASE_PROVENANCE.md`](../release/RELEASE_PROVENANCE.md).
