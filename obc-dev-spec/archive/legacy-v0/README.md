# Legacy Narrative Archive

此目錄保存 `formalize-obc-baseline` 之前的 13 份敘述版草稿，作為重編前的來源封存。

## 封存原因

- 舊稿依主題拆得較細，且同一組 command / telemetry / event 契約散落於多份文件中。
- 舊稿中仍混有舊索引、過時附錄連結，以及尚未對齊 OpenSpec CLI 真實工作流的流程描述。
- 正式基線建立後，`obc-dev-spec/` 改為 9 份 narrative source files，`openspec/specs/` 改為正式主規格。

## 對照原則

- 舊稿不再作為正式基準，但保留原文以供追溯。
- 新文件首頁均會標示來源對照與承接範圍。
- 後續若需查驗歷史敘述，以本目錄內容為準，不回寫新規格。
